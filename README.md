# NETLIFE CASH — Self-hosted Supabase

Two ways to deploy: **Portainer** (GUI) or **Ubuntu script** (one command).

---

## Option A — Ubuntu / Debian (one-command install)

```bash
# Upload this folder to your server, then:
chmod +x setup-ubuntu.sh
sudo ./setup-ubuntu.sh
```

**With a custom domain + SSL:**
```bash
sudo DOMAIN=supabase.yourdomain.com ./setup-ubuntu.sh
```

**With SMTP email:**
```bash
sudo DOMAIN=yourdomain.com \
     SMTP_HOST=smtp.yourdomain.com \
     SMTP_USER=user@yourdomain.com \
     SMTP_PASS=yourpassword \
     ./setup-ubuntu.sh
```

The script installs Docker, generates all secrets, starts the stack, pushes the
NETLIFE CASH schema, and creates the admin account automatically.

---

## Option B — Portainer Stack (GUI)

1. In Portainer → **Stacks** → **Add stack**
2. Name it `netlife-supabase`
3. Paste the contents of `docker-compose.yml`
4. Switch to the **Environment variables** tab
5. Load all values from `.env.example` (fill in passwords/keys)
6. Click **Deploy the stack**
7. After it's running, open a terminal on the `db` container and run:
   ```bash
   psql -U postgres < /docker-entrypoint-initdb.d/all_migrations.sql
   ```
   Or copy `all_migrations.sql` to the `db` container and run it.

## Useful commands

```bash
# View live logs
docker compose logs -f

# Restart everything
docker compose restart

# Stop
docker compose down

# Push schema manually
docker compose exec -T db psql -U postgres -d postgres < all_migrations.sql
```

## File layout

```
supabase-selfhost/
├── docker-compose.yml       ← Portainer / docker compose stack
├── .env.example             ← Environment variable template
├── .env                     ← Your actual secrets (auto-generated by setup.sh)
├── generate-keys.sh         ← Generate JWT keys manually
├── setup-ubuntu.sh          ← One-command Ubuntu install
├── all_migrations.sql       ← NETLIFE CASH full DB schema
└── volumes/
    ├── api/
    │   └── kong.yml         ← Kong API gateway config
    ├── db/
    │   └── init/            ← SQL that runs on first DB start
    └── storage/             ← Uploaded files
```
